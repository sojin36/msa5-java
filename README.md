# ☕ Java Practice

Java의 기본 문법부터 객체지향 프로그래밍까지 학습하고, 다양한 예제를 직접 작성하며 실습하는 Java 공부 기록입니다.

자료형, 연산자, 조건문, 반복문 등 기초 문법을 익히고 다형성, 예외 처리, 제네릭, 컬렉션 등 Java의 주요 개념을 단계별로 학습하고 있습니다.

## 📚 Study Contents

### 1. Java Basic

- Data Type : 기본 자료형과 참조 자료형
- Operator : 산술, 비교, 논리 등 다양한 연산자
- If : if, else if, else 조건문
- Loop : for, while 반복문
- 구구단 예제를 통한 반복문 활용 및 문제 풀이

### 2. Object-Oriented Programming

- OOP : 객체지향 프로그래밍의 기본 개념
- Polymorphism : 다형성의 개념과 활용
- 객체와 클래스, 메서드 등 객체지향 핵심 요소 학습

### 3. Exception Handling

- Exception : 예외의 개념과 종류
- try-catch를 활용한 예외 처리
- 예외 발생 상황과 처리 방법 실습

### 4. Date & Time

- Java 날짜 및 시간 관련 객체 학습
- 날짜와 시간 데이터 생성 및 활용
- 날짜와 시간 정보 다루기

### 5. Generics & Collection

- Generics : 제네릭의 개념과 사용 방법
- Collection : 컬렉션 프레임워크의 기본 개념
- Enum : 열거형을 활용한 상수 관리

## 🎯 Goal
